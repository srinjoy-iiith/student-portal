# Student Portal

A command-line student management system built in C++.

## Features
- Student record management
- User login and authentication
- Profile viewing and editing
- Dashboard with academic summary

## Prerequisites
- g++ (GCC) 9.0 or later
- A Linux/macOS terminal or WSL on Windows

## Build & Run
```bash
git clone git@github.com:srinjoy-iiith/student-portal.git
cd student-portal
g++ main.cpp -o student-portal
./student-portal
```
